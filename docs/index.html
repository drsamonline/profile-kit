A profile that themes itself, and updates itself.

profile-kit packages the hero banner, the stats card and the README generator behind a GitHub profile into one small, reusable kit — so anyone, including an AI agent, can lift it and get the same result.

The three ideas it combines

01 · HERO

A theme-aware hero

A hand-drawn SVG banner served through <picture> with media="(prefers-color-scheme: dark)" — the right artwork for each GitHub theme, with no JavaScript at all.

02 · METRICS

A card, rendered twice

lowlighter/metrics with the classic template, rendered once per theme into assets/metrics-light.svg and metrics-dark.svg. Each render pins its own palette.

03 · README

A self-updating README

A small Python script regenerates only the marked regions — a badge row and a categorised project list — from the GitHub API, and a workflow commits the result daily. Everything outside the markers is untouched.

Limitation — a silent failure worth knowing

The languages panel is empty under GITHUB_TOKEN. The base repositories query asks for stargazers { totalCount }, and a repository-scoped token is not permitted to read it — the call returns FORBIDDEN.

So the languages panel renders "0 Languages" with no chart, and the action still reports success, which means the card looks broken with no error to explain it. It is written down here because the alternative is someone discovering it weeks later and assuming their setup is wrong.
